# 🏏 IPL Auction Battle

A real-time multiplayer IPL-style cricket player auction game supporting up to 10 players per room.

## Features

- **Real-time Multiplayer**: Up to 10 players per room using Socket.IO
- **Team Selection**: Choose from 10 IPL teams or create custom teams
- **Live Auction**: Bid on cricket players in real-time
- **Per-Team Skip**: Skip players permanently per team without affecting others
- **Squad Management**: Track your squad composition and budget
- **Reconnection Support**: Rejoin if disconnected
- **Responsive Design**: Works on mobile, tablet, and desktop

## Quick Start

### Prerequisites
- Node.js 18+
- npm 9+

### Installation

```bash
# Clone the repository
git clone <your-repo-url>
cd ipl-auction-battle

# Install all dependencies
npm run install:all
